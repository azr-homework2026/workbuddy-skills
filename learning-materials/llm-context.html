LLM Context 学习笔记

占位页 —— 这里将整理 LLM 上下文窗口、Token 计数、上下文压缩、KV Cache 等概念。

1. Context Window

模型单次推理能看到的所有 token 总数上限。常见规格：

模型Context备注
GPT-4o128K≈ 9.6 万中文汉字
Claude Sonnet 4200K≈ 15 万中文汉字
Gemini 1.5 Pro1M–2M超长上下文

2. Token 估算经验值

  • 1 个英文 token ≈ 4 个字符
  • 1 个汉字 ≈ 1.5–2 个 token
  • 代码因符号多，token 密度更高

3. Context Engineering

把"提示工程"升级为"上下文工程"：合理组织 system / user / tool / history / retrieved 五大类信息。
