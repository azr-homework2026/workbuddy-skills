Skill 学习笔记

占位页 —— 这里将整理 WorkBuddy Skill 的写法、YAML frontmatter 规范、以及与普通 Prompt 的区别。

1. 什么是 Skill

Skill = 一份结构化的"工作流说明文档"。它告诉智能体：

  • 何时加载（description + read_when）
  • 如何执行（步骤、命令、约束）
  • 输出格式是什么

2. 最小 SKILL.md 模板

---
name: my-skill
description: 一句话说明在什么场景使用本 skill。
---

# my-skill

3. Skill vs Prompt

  • Prompt：单次会话内的指令
  • Skill：跨会话、可版本管理、可持续优化的能力包
