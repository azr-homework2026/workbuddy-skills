Agent 学习笔记

占位页 —— 这里将记录我对 Agent 概念的理解、典型架构、关键论文与代码示例。

1. 什么是 Agent

Agent 是一类能够感知环境 → 决策 → 行动的系统。与传统 LLM 应用的差别在于：

  • 工具调用：可以调用外部 API、代码执行器、浏览器等。
  • 循环迭代：能根据中间反馈调整下一步动作。
  • 长期记忆：具备跨会话的状态保持能力。

2. 典型架构

User → LLM(Reasoning) → Tool/Action → Observation → LLM → ... → Answer
