# workbuddy-skills

我的第一个 WorkBuddy 学习仓库。用来存放：

- `.workbuddy/skills/` —— 自己写的 Skill
- `learning-materials/` —— 学习 Agent / LLM / Skill 概念时的资料与笔记

## 仓库结构

```
workbuddy-skills/
├── .workbuddy/
│   └── skills/
│       └── learning-skill/      # 我的第一个 Skill
│           └── SKILL.md
├── learning-materials/
│   ├── agent.html
│   ├── llm-context.html
│   ├── skill.html
│   └── concept-relationship.html
├── README.md
└── .gitignore
```

## 快速开始

```bash
# 克隆
git clone https://github.com/azr-homework2026/workbuddy-skills.git
cd workbuddy-skills

# 查看 Skill
cat .workbuddy/skills/learning-skill/SKILL.md
```
