# concept-learning Skill — 使用说明

这个 Skill 帮你**对一个概念形成系统、深入、可核查的理解**，而不是停留在"百科第一段翻译"的水平。

## 触发方式

直接告诉 WorkBuddy：

> "用 concept-learning Skill 给我做一份 **Transformer** 的学习资料，我是中级工程师，想用在工程实践上。"

WorkBuddy 会加载这个 Skill，并按下面这套七段式流程跑。

## 七段式学习包长啥样

任何用本 Skill 产出的资料，都包含这 7 段（顺序固定）：

1. **学习目标** — 读完能做什么（动词开头）
2. **核心问题** — 从"是什么"问到"何时不用"
3. **结构化解释** — 体现你自己的理解，而不是百科复制
4. **应用案例** — 真实案例 + 反面案例
5. **概念辨析** — 跟最容易混淆的概念做对比表
6. **自测题** — 含答案，能检验你是否真的懂
7. **参考来源** — 全部真实 URL + 检索日期

## 三条硬规矩

### 1. 任何事实必须可追溯

如果一段话没有来源链接 / 出处，**这段话要么删，要么明确标注"未经核查，仅基于常识"**。

### 2. AI 初稿 ≠ 终稿

AI 写出来的东西只是初稿。你（人类作者）必须做两件事：

- **核查**：每条参考 URL 真的点开看过
- **理解**：把 AI 的解释用自己的话重写一遍，加自己的类比

否则你只是把 AI 的幻觉洗成了自己的幻觉。

### 3. 必须有学习目标 + 自测题

光讲不讲 → 等于没学。
光讲不练 → 看完就忘。

每份资料必须有目标、有题目，否则视为不合格。

## 怎么验证 Skill 真的在工作

加载 Skill 后，问 WorkBuddy 三个问题：

1. "请告诉我你这次检索到了哪些 URL？"
2. "你这份草稿里哪些段落属于'AI 默认套话'需要重写？"
3. "如果某条参考链接失效，你的 fallback 是什么？"

如果它答不上来，说明 Skill 没真正加载。
