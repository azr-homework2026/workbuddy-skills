# 去 AI 痕迹核查清单（de-AI Checklist）

> 交付前**逐条扫一遍**。命中任何一条 → 修改或删除，不要"差不多就行"。

## 一、开场套话（必删）

- [ ] "在当今时代……"
- [ ] "作为一个大语言模型……"
- [ ] "随着人工智能的快速发展……"
- [ ] "众所周知……"
- [ ] "想象一下……"
- [ ] "近年来，XXX 变得越来越重要……"
- [ ] 任何以"是的，没错"或"好问题"开头的回应（在学习资料里）
- [ ] 任何"我无法……但我可以……"式免责声明

## 二、模糊归因（必删或改写）

- [ ] "研究表明……" — 改成"某某团队 2023 年的研究 [3] 发现……"
- [ ] "某权威机构指出……" — 改成具体机构名 + 来源
- [ ] "专家普遍认为……" — 改成具体的 N 个专家 + 来源
- [ ] "大量数据显示……" — 给出具体数据 + 来源
- [ ] "通常情况下……" — 给出具体条件 + 边界

## 三、排比 / 三段式堆砌（删到 ≤ 1 处）

- [ ] "速度快、效率高、质量好" 式无信息密度的排比
- [ ] "它不仅 X，而且 Y，更 Z" 式的三段递进（X、Y、Z 没有信息增量时）
- [ ] "一是……二是……三是……"（用真正的子标题替代）

## 四、空泛类比（替换为具体类比）

- [ ] "它就像一座桥梁" — 桥连接了什么？连接的方式有什么限制？
- [ ] "它就像是大脑" — 大脑的哪个部分？哪个机制？
- [ ] "如同生活中的 XXX" — 这个类比是否揭示了机制，还是只是套话？

**类比最低标准**：
- 必须揭示**机制对应**，不仅是外形相似
- 必须能预测**至少 1 个**反直觉行为
- 必须能指出**类比的失效边界**

## 五、形容词滥用

- [ ] "强大的"、"高效的"、"优雅的"、"革命性的"、"颠覆性的"
- [ ] "极致的"、"完美的"、"无与伦比的"
- [ ] 把每个概念都说成"重要"或"关键"

**替换原则**：用数据 / 对比 / 反例替代形容词。

| 原文 | 改写 |
|------|------|
| Transformer 是一种强大的模型 | Transformer 在 WMT 2014 英德翻译任务上把 BLEU 从 28.4 提到 28.4+（Vaswani et al., 2017） |
| 该算法非常高效 | 在 100 万样本上训练耗时从 8h 降到 1.5h（X 平台 A100 ×8） |

## 六、自我引用

- [ ] 不再写"作为 AI"、"我"——学习资料应以**作者**或**概念本身**为主语
- [ ] 把"我建议你"改为"建议"
- [ ] 把"我会为你解释"改为"本节解释"

## 七、过渡词成瘾

- [ ] "此外"、"而且"、"不仅如此"、"与此同时" 出现频率 > 3 次/千字 → 删
- [ ] "总而言之"、"综上所述" → 如果前面没有真正复杂的论述就别用
- [ ] "首先……其次……最后……" → 用子标题替代

## 八、结构性 AI 痕迹

- [ ] 每段都恰好 3 句（说明是在堆排比）
- [ ] 每个 bullet 都以动词开头（说明在硬套"动词列表"模式）
- [ ] 用 emoji 装饰每一个标题（🎯、🚀、💡 滥用）
- [ ] 把所有"挑战"和"未来工作"放在最后两段（套话式收尾）
