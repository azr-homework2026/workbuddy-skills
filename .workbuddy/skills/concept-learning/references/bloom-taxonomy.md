# 布鲁姆分类法速查（用于学习目标 & 自测题设计）

> 写学习目标时选一个动词 → 对应一个认知层级 → 自测题必须覆盖至少 3 个层级。

## 六层认知层级（修订版，2001 Anderson & Krathwohl）

由低到高：

| 层级 | 中文 | 关键动词 | 典型题型 | 反例（避免使用） |
|------|------|----------|----------|------------------|
| 1. Remember | 记忆 | 列出、复述、识别、命名 | 填空、选择 | "了解"（太虚） |
| 2. Understand | 理解 | 解释、归纳、分类、举例 | 简答、画图 | "理解"（本身就是这一层） |
| 3. Apply | 应用 | 计算、执行、使用、实现 | 情境题、上机 | "会用" |
| 4. Analyze | 分析 | 比较、区分、归因、拆解 | 对比题、因果链 | "分析"（本身就是这一层） |
| 5. Evaluate | 评价 | 评判、辩护、选择、监控 | 案例评估、辩论 | "评价" |
| 6. Create | 创造 | 设计、构造、规划、提出 | 设计题、开放题 | "创造" |

## 学习目标动词对照表

写"完成本资料后，你能……"时，按下表选动词：

| 层级 | 推荐动词 |
|------|----------|
| Remember | 列出、复述、识别、命名、定义 |
| Understand | 解释、归纳、对比、举例说明、画图示意 |
| Apply | 计算、实现、调用、使用、套用 |
| Analyze | 区分、归因、拆解、识别假设 |
| Evaluate | 评判、辩护、选择最优方案、指出局限 |
| Create | 设计、构造、组合、提出新方案 |

## 自测题最低覆盖

一份合格的自测题集，应覆盖 **至少 3 个层级**，理想是 4 个。

推荐分布（5–8 题）：

- 1–2 题 Remember / Understand（基础）
- 2 题 Apply（动手）
- 1–2 题 Analyze（辨析 / 拆解）
- 0–1 题 Evaluate 或 Create（拔高）

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 8 道题全是 Remember | 看完不会用 | 加入 Apply、Analyze 题 |
| 用"了解"、"理解"做目标动词 | 无法衡量是否达成 | 换成"列出"、"解释"、"比较" |
| Evaluate 题写成"谈谈你的看法" | 没有评判标准 | 给出明确的评判维度或对照表 |
| Create 题过于宏大（"设计一个 OS"） | 答不出来 | 缩小到 1 小时能完成的小任务 |
